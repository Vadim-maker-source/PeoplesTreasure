# Context

goal: перенести «Сокровища народов» в нативное мобильное приложение, в котором изучение народов, чтение публикаций, прохождение тестов и общение ощущаются быстрыми и естественными

user: русскоязычные пользователи 14+, преимущественно смартфоны Android и iPhone, смешанный уровень технической грамотности

JTBD: открыть приложение, быстро найти интересующий народ или публикацию, сохранить прогресс и взаимодействовать с сообществом без перехода на сайт

constraints: Flutter 3.41+, Material 3 с адаптацией под iOS, существующий Next.js/PostgreSQL backend, единая база пользователей и контента, мобильный API под `/app/api/mobile/v1`, визуальное направление Telegram + iOS 18

success: запуск до первого полезного экрана без тупиков; основные действия доступны не более чем за 3 нажатия; touch targets не меньше 44 px; плавные переходы; авторизация и обновление токена переживают перезапуск; `flutter analyze`, тесты и production Next.js build проходят

scope v1: [вход и регистрация по email, лента и фильтры, карточка публикации, комментарии и лайки, каталог и карточка народа, тесты и прогресс, создание публикации, профиль, обращения в поддержку, админские разделы по роли]

non-goals: [офлайн-синхронизация контента, push-уведомления, Yandex OAuth внутри приложения, публикация в App Store и Google Play в этом этапе]

assumptions: [существующие четыре народа являются стартовым каталогом, медиа продолжают храниться в Yandex Object Storage, production API будет доступен по HTTPS, для локального Android используется 10.0.2.2]

risks: [iOS-сборка не проверяется на Windows, мобильная загрузка видео зависит от доступности Object Storage, полноценная проверка accessibility с VoiceOver и TalkBack требует физических устройств]
