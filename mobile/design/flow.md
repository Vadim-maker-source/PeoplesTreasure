# App flow

## Nodes

- launch: восстанавливает защищённую сессию и открывает auth или main
- auth: вход, запрос кода, регистрация
- feed: лента, поиск, фильтр, публикация
- post: полный текст, медиа, лайк, комментарии
- create: новая публикация и отправка на модерацию
- peoples: каталог народов
- person: описание, факты, культура, кухня, история и запуск квиза
- quiz: вопросы, результат и сохранение прогресса
- support: список обращений, новое обращение, ответы
- profile: данные пользователя, прогресс, выход
- admin: ожидающие публикации и обращения поддержки

## Edges

- launch -> auth: сессия отсутствует или refresh-токен недействителен
- launch -> feed: сессия восстановлена
- auth -> feed: успешный вход или регистрация
- feed -> post: нажатие на карточку
- feed -> create: центральная кнопка навигации
- peoples -> person -> quiz: выбор народа и запуск проверки знаний
- profile -> admin: роль пользователя ADMIN
- profile -> auth: выход
- admin -> post: просмотр публикации перед модерацией

## State ownership

- auth session: AuthController, access/refresh токены в secure storage
- tab selection: MainShellState
- remote collections: screen controllers с повторной загрузкой и pull-to-refresh
- forms: локальное состояние экрана, серверная ошибка показывается рядом с действием
- optimistic actions: лайк обновляется сразу и откатывается при ошибке

## Required states

- loading: skeleton/indeterminate progress без блокировки навигации
- empty: конкретное следующее действие
- error: понятный текст и кнопка повторить
- success: содержимое с pull-to-refresh
- permission: недоступные admin-действия не показываются

## Back behavior

- системный back закрывает detail/form и возвращает прежнюю вкладку
- повторное нажатие активной вкладки возвращает список к началу
- незавершённая форма публикации требует подтверждения перед закрытием
